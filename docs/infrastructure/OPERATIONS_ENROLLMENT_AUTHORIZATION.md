Ветка ops/bounded-vps-enrollment доставляет исходники; она не меняет утверждённый
source pin и не выполняет root install. Сначала hosted validate, затем только
source staging существующим одноразовым runner. После его завершения root
снимок bootstrap проверяется по указанному SHA-256 и вызывается с exact approvals.
Для публичного root-owned кода/metadata используется scoped umask 022; private
key и private directories сохраняют явные режимы 0600/0700. Глобальная umask
SSH-сеанса или политики безопасности не меняются.

Прямого Cloud SSH-доступа и credentials в текущей среде нет; администраторские
команды первоначальной установки выполняет владелец в своём SSH-сеансе.
