## Важное ограничение готовности

Приложение пока запускает worker через rootful Docker socket. Безопасный broker
и adapter для отдельного rootless execution daemon **не реализованы**; rootless
не устраняет shared-kernel risk. Изменение launcher — отдельная будущая задача,
не молчаливое исправление в этом пакете. MFA/HTTPS/VPN, offsite и независимый
watchdog также ещё не настроены. Compose пример содержит только control plane
и явно помечен `deployable=false`; это не полный deploy-ready F1.

Пакет готовится для ревью и будущего поэтапного применения. Ни наличие файлов,
ни PASS offline validation не разрешают запуск. Нет apply/install/deploy скрипта.
