## Следующая ограниченная работа

1. Сравнить текущую модель с более сильным кандидатом на одинаковых записях.
   Не менять production по одному примеру и не считать больший beam гарантией.
   Локальный кандидат — без runtime download; измерить RAM, задержку и качество.
   Облачный кандидат требует отдельного согласия на аудиопередачу и расходы.
2. Проверять отдельно обычные слова, пунктуацию и критические поля. Нужны примеры
   без срока, с отрицанием, самокоррекцией, относительной датой, несколькими
   поручениями, именами и похожими названиями; тихая и шумная речь. Эталон —
   подтверждённое владельцем содержание, не предположение оператора.
3. До календарной записи показать абсолютную дату, время, часовой пояс,
   продолжительность, место и название. Неизвестное поле не придумывать;
   неоднозначность уточнять. Проверить пересечения и повторную доставку.
   Подтверждение текста не является подтверждением календарного действия.
4. Для использования без экрана подготовить краткое голосовое прочтение
   критических полей и исправление обычным сообщением. Сейчас голосовой
   readback/исправление и Calendar write не приняты и не объявляются готовыми.

Кандидат не принимается, если на согласованном наборе остались незамеченные
подмены критических полей; отсутствие ошибок в наборе не гарантирует их
отсутствия в будущем. Неуверенное распознавание должно вести к уточнению,
а не к молчаливой записи на предполагаемую дату. Низкий word error rate
сам по себе не доказывает безопасность действий.

Платных вызовов нет. Google bridge остаётся read-only. Новая модель,
source deployment и расширение Google scope требуют конкретного разрешения.

runtime не менялся.

## Локальный инструмент сравнения

`scripts/speech_quality.py` загружает только точный локальный snapshot из четырёх
файлов, сверенных по SHA-256. Нет Telegram, API, скачивания модели или операций
с календарём. Для каждого варианта запускать отдельный процесс: int8/CPU/1 thread,
beam1 либо5. Формат JSON списка примеров:

```json
[{"id":"negation","audio":"audio/negation.wav",
  "reference":"Не переноси встречу с Анной.",
  "critical_phrases":["Не переноси", "Анной"]}]
```

```powershell
.venv/Scripts/python.exe scripts/speech_quality.py --model PATH_TO_EXACT_MODEL --manifest MANIFEST.json --cases CASES.json --beam 5 --output .runtime/quality-report.json
```

В отчёте нет исходного текста или расшифровок; есть хеши audio/reference,
ошибки слов, индексы несовпавших критических фраз, время decode+inference и
peak working set. Списки примеров и аудио с персональными данными держать вне Git.
WER — лексическая метрика: «15»/«пятнадцать» и «послезавтра»/«после завтра»
могут различаться без изменения намерения. Отметка означает ручную проверку,
а не доказанную семантическую ошибку. Совпадение последовательности знаков
пунктуации не проверяет их расположение или читаемость. Индексы критических
фраз также не выявляют все возможные противоречия и лишние поручения.
Поэтому отчёт всегда требует человеческой проверки и не разрешает действие.
